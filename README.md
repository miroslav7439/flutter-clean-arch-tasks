# TaskTracker (Flutter + Clean Architecture)

## Політика гілкування (Git Flow)
- `main` — стабільний код, готовий до випуску релізів.
- `develop` — основна інтеграційна гілка розробки, куди зливаються завершені задачі.
- `feature/*` — ізольовані гілки для розробки окремих архітектурних шарів та функціоналу (`feature/domain-layer`, `feature/application-layer`, `feature/infrastructure-layer`, `feature/presentation-layer`).
